# Color Palette

## Theme Modes

Choose based on context. Default to **light** for general use. Use **dark** for brand-aligned presentations, YouTube content, or embedded diagrams on dark backgrounds.

| Setting | Light Mode | Dark Mode |
|---------|------------|-----------|
| `viewBackgroundColor` | `#ffffff` | `#222222` |
| Text (titles) | `#312e81` | `#c7d2fe` |
| Text (subtitles) | `#6366F1` | `#a5b4fc` |
| Text (details) | `#64748b` | `#94a3b8` |
| Code block bg | `#1e293b` | `#1a1a1a` |

## Brand Accents (Use Sparingly)

| Purpose | Hex | When |
|---------|-----|------|
| Orange (CTA/Energy) | `#FF9000` | Call-to-action elements, emphasis arrows |
| Cyan (Data) | `#43C2D2` | Data visualization, metrics, analytics |

## Neutrals

| Name | Hex | Use |
|------|-----|-----|
| Charcoal | `#374151` | Text on light fills |
| Slate | `#64748b` | Secondary text, borders |
| Light Gray | `#e5e7eb` | Backgrounds, subtle fills |

## Rules

- Always pair darker stroke with lighter fill for contrast.
- On dark backgrounds, use lighter fill variants and lighter text colors.
- Use brand orange (#FF9000) and cyan (#43C2D2) as spot accents only, not as primary shape fills.
